## Naming Conventions

**Files:**
- Pattern: PascalCase with .md extension for main notes
- Example: `Resources.md`
- Config files: lowercase with .json extension
- Internal links reference: `[[PascalCase]]` for wikilinks

**Directories:**
- Pattern: lowercase with hyphens for multi-word directories
- Example: `.obsidian`, `.planning`
- Standard Obsidian structure

**Markdown Content:**
- Pattern: Use `[[wikilink]]` syntax for cross-references
- Pattern: Use `#tag` for categorical tagging
- Pattern: Optional YAML frontmatter for metadata

## Configuration File Details

**workspace.json:**
- Stores active file, split view state, sidebar open/close, zoom level
- Obsidian updates this automatically on changes
- Safe to edit manually for bulk workspace changes

**app.json:**
- Application preferences (editor settings, hotkeys, etc.)
- User editable via Obsidian preferences UI or manual JSON editing
- Format: JSON key-value pairs

**core-plugins.json:**
- Lists enabled Obsidian core plugins
- Format: JSON object with plugin names as keys
- Examples: editor, file-explorer, graph, search, etc.

**graph.json:**
- Knowledge graph visualization settings (node colors, link appearance, etc.)
- Format: JSON configuration for graph renderer
- Obsidian updates this when graph settings change in UI

**appearance.json:**
- Theme, accent color, and visual settings
- Format: JSON configuration for UI theming
- User editable via Obsidian appearance settings
