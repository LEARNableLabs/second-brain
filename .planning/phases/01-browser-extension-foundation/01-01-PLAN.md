  <action>
Create the extension project from scratch in the `extension/` directory at the project root.

1. Initialize npm project and install dependencies (exact versions from RESEARCH.md):
   ```bash
   mkdir -p extension && cd extension && npm init -y
   npm install -D wxt@0.20.20 typescript@^5.5 vitest@4.1.4
   npm install webextension-polyfill@0.12.0 zod@^4.3
   npm install -D @types/webextension-polyfill
   ```

2. Create `extension/wxt.config.ts`:
   ```typescript
   import { defineConfig } from 'wxt';

   export default defineConfig({
     srcDir: '.',
     manifest: {
       name: 'Second Brain Capture',
       version: '1.0.0',
       description: 'Passively captures browsing activity for your Obsidian vault',
       permissions: ['tabs', 'history', 'webNavigation', 'storage'],
       host_permissions: [],
       action: {
         default_popup: 'popup/index.html',
         default_icon: {
           '16': 'icon-16.png',
           '48': 'icon-48.png',
           '128': 'icon-128.png',
         },
       },
     },
   });
   ```
   CRITICAL: Do NOT include `<all_urls>` or `https://*/*` in permissions (per Pitfall 2 in RESEARCH.md -- Web Store rejection risk). Only `tabs`, `history`, `webNavigation`, `storage`.

3. Create `extension/tsconfig.json`, `extension/vitest.config.ts`, and `extension/.gitignore` with standard configurations. tsconfig must have `"strict": true`. vitest must include `tests/**/*.test.ts`. gitignore must exclude `node_modules/`, `.output/`, `.wxt/`, `dist/`.

4. Add scripts to `extension/package.json`: `dev` (wxt), `build` (wxt build), `test` (vitest run), `test:watch` (vitest), `type-check` (tsc --noEmit).
