| Boundary | Description |
|----------|-------------|
| active tab URL | Current tab URL read via browser.tabs.query -- could be any URL |
| user input (toggle) | Pause toggle is trusted (user action) but persisted state must be validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-09 | Information Disclosure | popup/main.ts | mitigate | Do not display full URLs in popup -- only show domain name in block button |
| T-01-10 | Tampering | popup/main.ts addToBlocklist | accept | User intentionally adds domains to blocklist -- this is expected behavior, not a threat |
| T-01-11 | Denial of Service | popup/main.ts | mitigate | Try-catch around URL parsing for tab.url; disable block button if URL parsing fails |
