# Phase 1 — UI Design Contract

> Visual and interaction contract for the browser extension popup. Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (browser extension popup) |
| Preset | not applicable |
| Component library | none (vanilla HTML + TypeScript via WXT) |
| Icon library | none (extension uses manifest icons) |
| Font | system-ui (native OS font stack) |

---

## Spacing Scale

Declared values (multiples of 4, scoped to popup ~300px width):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, button padding |
| md | 16px | Default element spacing, section padding |
| lg | 24px | Section gaps within popup |
| xl | 32px | Popup body padding |

Exceptions: No 48px or 64px tokens — popup is too small for large spacing values.

## Popup Layout

```
┌─────────────────────────────────┐
│  Second Brain          [toggle] │  ← heading + pause/resume toggle
│─────────────────────────────────│
│                                 │
│   47           2 min ago        │  ← stat number (24px/600)
│   Pages today  Last capture     │  ← stat label (13px/400, secondary)
│                                 │
│─────────────────────────────────│
│  [Block this site: example.com] │  ← destructive button, full-width
│                                 │
│  [Edit blocked sites]            │  ← text link, secondary color
└─────────────────────────────────┘
```

**Popup dimensions:** 320px width, auto height (~180px typical)

**States:**
- **Active:** Green dot or no indicator, toggle shows "Pause capture"
- **Paused:** Amber badge, toggle shows "Resume capture", stats still visible but dimmed
- **Empty (0 captures):** Stats section replaced with empty state copy
- **Quick-block toast:** Appears inline below the block button for 3 seconds, then fades
