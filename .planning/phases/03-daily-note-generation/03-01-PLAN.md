    **Create `pipeline/src/generators/markdown.ts`:**

    Export the following functions:

    1. `escapeMarkdown(text: string): string` — Escape markdown special characters in text (not URLs). Replace `[`, `]`, `(`, `)`, `*`, `_`, `#`, `` ` ``, `\` with backslash-prefixed versions. Use regex: `/([\\`*_\[\]()#+\-!])/g`.

    2. `formatEntry(entry: CaptureRow & { description?: string }): string` — Per D-04 and D-06:
       - Extract path from URL via `new URL(entry.url).pathname` for the display path after em dash
       - For manual source (per D-06): prefix with `⭐ `
       - Build: `- ${prefix}[${escapeMarkdown(entry.title)}](${entry.url}) — ${entry.domain}${pathname}${suffix}`
       - For backfill source (per D-06): append ` *(from history)*` suffix
       - If description exists, add second line: `  ${description}` (two-space indent)
       - Return the line(s) as a string

    3. `groupByDomain(entries: CaptureRow[]): Record<string, CaptureRow[]>` — Group entries by `entry.domain`, sort domain keys alphabetically using `localeCompare`. Entries within each domain keep their original order (timestamp ASC from database).

    4. `generateDailyNote(date: string, entries: CaptureRow[], descriptions?: Map<string, string>): string` — Per D-01:
       - Call `renderFrontmatter(date, entries)` for YAML block
       - Add `\n## Highlights\n\n*AI-curated summary will appear here after Phase 5*\n\n`
       - Add `## Browsing Log\n\n`
       - Call `groupByDomain(entries)` to get domain groups
       - For each domain (alphabetically per discretion choice): add `### domain.com\n\n`
       - For each entry in domain: call `formatEntry()` with description from the descriptions Map if available, add result + `\n`
       - Add blank line after each domain group
       - Return complete markdown string

    Import `CaptureRow` from `../db/operations.js`.
