    Export interface:
    ```typescript
    export interface MetaResult {
      description?: string;
      error?: string;
    }
    ```

    Export `fetchMetaDescription(url: string): Promise<MetaResult>`:
    - Use native `fetch()` with `AbortSignal.timeout(5000)` (5-second timeout per research recommendation)
    - Set `User-Agent: 'SecondBrain/1.0 (Knowledge Capture)'` header
    - If response is not OK, return `{ error: 'HTTP ${response.status}' }`
    - Parse HTML with `cheerio.load(html)`
    - Try `$('meta[property="og:description"]').attr('content')` first (more reliable)
    - Fall back to `$('meta[name="description"]').attr('content')`
    - Return `{ description: description.trim() }` if found, else `{ error: 'No description found' }`
    - Catch errors: TimeoutError -> `{ error: 'Timeout after 5s' }`, other errors -> `{ error: err.message }`

    Export `fetchAllDescriptions(urls: string[]): Promise<Map<string, string>>`:
    - Use `Promise.allSettled()` to fetch all URLs in parallel
    - Return a `Map<string, string>` where key is URL and value is description
    - Only include URLs where description was successfully fetched (skip errors)
    - Log errors to stderr for debugging: `console.error(`Meta fetch failed for ${url}: ${error}`)`

    **Test strategy for meta-fetcher.test.ts:**
    - Do NOT make real HTTP requests in tests
    - Mock `global.fetch` using `vi.fn()` to return controlled HTML responses
    - Create helper function `mockFetchResponse(html: string, status = 200)` that sets up the mock
    - Reset mock in `afterEach`

    ```typescript

    }
    ```

    Implementation flow (per D-13):

    1. **Determine date:** `options.date || new Date().toISOString().split('T')[0]` (YYYY-MM-DD)
    2. **Log start:** `console.error('Generating daily note for ${date}...')`
    3. **Load config:** `const config = await loadConfig()` then `const outputDir = getOutputDir(config)` (STOR-05, D-14)
    4. **Open database:** `const db = getDatabase()` — wrap everything in try/finally with `closeDatabase(db)`
    5. **Run migrations:** `const { applied } = migrate(db)` — log if applied > 0
    6. **Fetch captures:** `const captures = getByDate(db, date)` — if empty, log "No captures found for ${date}" and return
    7. **Log count:** `console.error('Found ${captures.length} captures for ${date}')`
    8. **Fetch meta descriptions:** `const descriptions = await fetchAllDescriptions(captures.map(c => c.url))` (D-05)
    9. **Generate markdown:** `const markdown = generateDailyNote(date, captures, descriptions)` (NOTE-01, NOTE-02)
    10. **Dry run check:** If `options.dry`, print markdown to stdout and return
    11. **Ensure git repo:** `await ensureGitRepo(outputDir)` (STOR-06, D-10)
    12. **Write file:** `const filename = '${date}.md'`, `const filepath = path.join(outputDir, filename)`, `await saveNote(filepath, markdown)` (D-09)
    13. **Log write:** `console.error('Wrote ${filepath}')`
    14. **Update status:** For each capture, `updateStatus(db, capture.url, date, 'written')` (status pipeline progression)
    15. **Auto-commit:** `const committed = await autoCommitNotes(outputDir, [filename])` — log if committed (STOR-06, D-11)
    16. **Catch errors:** Wrap in try/catch, log to stderr, set `process.exitCode = 1`

    **Important:** Use `console.error()` for progress messages and `console.log()` only for the dry-run markdown output. This keeps stdout clean for piping.
